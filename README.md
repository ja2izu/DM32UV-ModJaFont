# DM32UV-ModJaFont Ver 0.99

Baofeng **DM-32UV**（DP570UV）の内蔵フォントに、日本語の漢字・かな・記号を足す差分パッチと、書き込みツールです。
チャンネル名・ゾーン名・連絡先などに、日本語を表示できるようになります。

名前の書き込みには、姉妹プロジェクトの **[NeonPlugJA](https://github.com/ja2izu/NeonPlugJA)**（ブラウザで動く書込ソフト）を使います。
このフォントが入った無線機に接続すると、NeonPlugJA は日本語名を自動で有効にし、機種名の横に **ModJaFont** と表示します。

> **ご注意**
> - 無線機のフラッシュを書き換えます。**自己責任**でお使いください。無保証です。作者は、使用により生じた損害に責任を負いません。
> - 書き込む前に、**必ず無線機のフルダンプ（OpenUV008 など）を取ってください。** このリポジトリには Baofeng 純正のフォントは含まれていないので、元に戻せるのは、利用者自身が取ったバックアップだけです。
> - 作者の無線機で確認した手順です。ファームウェアの版や個体による違いは未確認です。

## 仕組み

1. 自分の無線機から、フォント3領域（Radio_Y16 / HZK24S / HZK24T）を**読み出す**（`dm32_fonttool.py read`）。
2. 読み出したフォントに、**差分パッチ**を重ねる（`dm32_fontpatch.py apply`）。
3. できたファイルを、無線機に**書き込む**（`dm32_fonttool.py write`）。書き込む前に自動でバックアップを取り、書いた後に全ブロックを読み直して照合します。

パッチには、Baofeng 純正のデータは含まれていません。含まれるのは、日本語の字形（JIS X 0208 の 6,879 字）と、未割当スロットの印（□に×）だけです。純正のデータは、利用者自身の無線機から読み出したものを使います。

手順の詳細は **[docs/MANUAL.md](docs/MANUAL.md)** を見てください。

## 内容

| パス | 内容 |
|---|---|
| `tools/dm32_fonttool.py` | 無線機の情報表示（`info`）、フォント読み出し（`read`）、書き込み（`write`）、校正データの保存（`calread`・読み出しのみ） |
| `tools/dm32_fontpatch.py` | 差分パッチの適用（`apply`）と内容表示（`info`）。`make` は開発者用 |

| `SHA256SUMS` | 上のファイルの SHA-256 |

必要なもの: Python 3、`pip install pyserial`、プログラミングケーブル（CH340、FTDI で動作を確認）。

## 文字の割り当て（master_1990_v2）

無線機の名前は GB2312 の2バイトで引かれます。

- GB2312 にある漢字（3,331 字）は、そのまま使います。
- GB2312 に無い日本の字（3,070 字）と、かな・全角英数記号など（332 字）は、日本語では使わない中国漢字の区点に、日本語の字形を焼いて割り当てます。かなを GB2312 の区4・5 のままにしないのは、16 ドット表示にかなの字形が無く、緑のベタで表示されたためです。
- ギリシャ文字・キリル文字・罫線（146 字）は、GB2312 の区点のままです（24 ドット表示の字形だけを、JIS のものに入れ替えます）。
- 割り当てが無いスロットは、□に×の印にします。供出枠の空きは 30 です。

一覧は `data/master_1990_v2.csv`（列: `char,kind,ku,ten,gb_hex,in_jis`）にあります。
JIS X 0208 に無い異体字（`髙` `﨑` `𠮷` など）は、対応していません。

## 字形の出所と権利

- **字形**: パッチ内の日本語の字形は、`jiskan16` / `jiskan24` のビットマップ（JIS X 0208-1990 の字）から作りました。BDF ヘッダの著作権表記は「from JIS X 9051-1984（16 ドット）/ JIS X 9052-1983（24 ドット）, by permission to use」です。**再配布・改変の可否は、ヘッダだけでは判断できておらず、未確認です。** 権利者から指摘があれば、パッチを差し替えるか削除します。
  - `凜`（U+51DC）は、24 ドットは合成した字形、16 ドットは `凛` の字形の流用です。
- **Baofeng 純正のフォント**: このリポジトリには含みません。また、再配布しないでください。
